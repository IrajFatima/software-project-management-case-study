# 🧠 Project Overview — Vendora

Vendora is an AI-enabled eCommerce platform designed to help small online sellers automate product content generation.

## Business Problem

Small sellers often spend excessive time writing product titles and descriptions, resulting in:

* inconsistent listings
* weak SEO performance
* poor presentation quality
* reduced conversion potential

## Proposed Solution

Vendora integrates AI-assisted content generation directly into the seller workflow, allowing users to generate professional product descriptions using only a few keywords.

# 📌 Key Project Management Decisions

Several management decisions were critical to keeping the project on schedule and within scope:

* Reduced initial feature scope to protect MVP delivery timeline
* Prioritized checkout reliability over secondary feature expansion
* Introduced fallback planning for potential AI API instability
* Enforced strict MVP boundaries to prevent scope creep
* Conducted phased validation reviews to reduce late-stage rework
* Maintained centralized documentation governance across all project phases
